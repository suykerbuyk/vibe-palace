# Review Plan — Architecture Review

Perform a critical architecture review of a task plan before implementation begins.

## Review Checklist

1. **Scope**: Does the plan match what was requested? No scope creep?
2. **Dependencies**: Are all prerequisites met? Any missing imports or packages?
3. **Existing patterns**: Does the plan reuse existing code patterns and utilities?
4. **Test strategy**: Is the test plan concrete? Will it achieve 80%+ coverage?
5. **Edge cases**: Are error paths, empty states, and boundary conditions handled?
6. **Simplicity**: Is this the simplest approach that solves the problem?
7. **Impact**: Does it minimize changes to existing code?

## Output

Provide a brief verdict: approve, approve with changes, or reject with reasons.
List any specific concerns or suggestions for improvement.

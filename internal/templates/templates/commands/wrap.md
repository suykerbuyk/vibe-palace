# Wrap — Session Capture

Capture the current work session for {{PROJECT}} before ending.

## Steps

1. Summarize what was accomplished in 2-3 sentences.

2. Record the session with `vp_capture_session` including:
   - **summary**: What was accomplished
   - **tag**: implementation | debugging | refactor | exploration | review | docs | planning
   - **decisions**: Key technical decisions made
   - **files_changed**: Files created or modified
   - **open_threads**: Unresolved items or follow-up work

3. Update the resume if the project state has meaningfully changed
   (new phase, test count change, new open threads).

4. If any tasks were completed, retire them and record an iteration summary.

Write summaries that help a developer resuming this work tomorrow.

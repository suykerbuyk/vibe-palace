# internal/templates/shipped.txt — the shipped-version manifest.
#
# Every version of every built-in template that a vp binary could ever have
# written into a vault's Templates/, one row per (version, relpath), in
# sha256sum format: "<ProvenanceKey>  <relpath under internal/templates/templates/>".
# `vp config sync` prunes a vault Templates/ copy whose bytes, line endings
# aside, match a row for its own relpath: those bytes are vp-shipped, and
# recoverable from vibe-palace's git history. The current embedded copy is
# matched live (templates.EmbeddedSHA) and is not a row.
#
# FROZEN. It is never regenerated, and a template edit needs nothing beyond
# the Go-embedded copy. A change to this file is a deliberate, reviewed edit
# that updates frozenManifestSHA256 (shipped_test.go) in the same commit.
#
# The boundary is 1f3bb62: the last commit on main before a4179a5 removed the
# last writer of template bytes into a vault (the upgrade commands' reset).
# The writers were TemplateTree materialize (7e5b96d..807bae7), config sync's
# `o`/--yes overwrite (until 5aa68ee), `vp commands upgrade` (44df171..a4179a5)
# and `vp skills upgrade` (a7e24c9..a4179a5). After the boundary no vp binary
# writes a template into Templates/, so no later version can reach a vault from
# vp: a copy of one is operator-placed, kept, and reported by vp_check.
#
# Key: sha256 of the bytes after one CRLF->LF pass (templates.ProvenanceKey).
# No row's blob holds a CR, so every row equals a plain sha256sum.
#
# Residuals, all failing toward keep: versions that existed only in
# rebased-away commits, fixups or dirty `make install` builds before the
# boundary; mirrors written by pre-vibe-palace (vibe-vault) binaries, whose
# history starts at f9f5b17; and a built-in later removed from the corpus,
# whose rows are never consulted because the reconcile walks only the current
# relpaths. Rows under old relpaths (commands/vp-*.md) stay: they are part of
# the derivation.
#
# Derivation. Run it once in a full clone with tags fetched (git fetch --tags).
# It fails closed: a revision that does not resolve is a non-zero exit, never
# zero rows. The rows below, with every "#" line stripped, equal its output:
# 174 rows over 46 relpaths. With revs="1f3bb62" alone it yields 172; the two
# rows marked "# extra:" come from the tag pre-rebase-501c96e, whose commit is
# not an ancestor of 1f3bb62 but whose build was installed.
#
#   set -eu -o pipefail
#   revs="1f3bb62 pre-rebase-501c96e"
#   for r in $revs; do git rev-parse -q --verify "$r^{commit}" >/dev/null || { echo "derive: $r does not resolve (git fetch --tags)" >&2; exit 1; }; done
#   git rev-list --full-history $revs -- internal/templates/templates internal/context/templates \
#    | while read -r c; do git ls-tree -r "$c" -- internal/templates/templates/ internal/context/templates/ || exit 1; done \
#    | awk '$2=="blob" && $4 ~ /\.md$/ {sub("^internal/(templates|context)/templates/","",$4); print $3" "$4}' | LC_ALL=C sort -u \
#    | while read -r oid rel; do s=$(git cat-file blob "$oid" | sha256sum) || exit 1; printf '%s  %s\n' "${s%% *}" "$rel"; done \
#    | LC_ALL=C sort -k2,2 -k1,1 -u
#
